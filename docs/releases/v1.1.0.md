# Redact v1.1.0 Release Notes

Redact v1.1.0 strengthens the stable deterministic local redaction-aid
contract without changing its schema majors. It requires the signed Kujo 1.5.0
runtime and keeps the documented CLI, policy, verifier, audit, pack, JSON, and
exit-code interfaces compatible with Redact 1.x.

Highlights include:

- safer policy parsing for ambiguous booleans, mappings, malformed names, and
  dictionary categories;
- corrected detector spans, uppercase default output names, policy-file
  overwrite protection, and ten earlier CLI and transformation regressions;
- bounded no-follow reads, output and dictionary work budgets, literal path
  validation, and stronger Unicode boundary coverage;
- private pack staging with atomic no-replace publication, interruption intent
  records, and read-only audit reconciliation; and
- deterministic performance improvements for frequent ASCII dictionary terms,
  with expanded Unicode, repetition, replacement, and aggregate-pack checks.

The exact release candidate is verified locally and through hosted Linux,
macOS, Windows, ShipCheck, Kennel, and isolated Workcell gates. These checks
establish the documented technical contracts; they do not certify complete PII
detection, compliance, arbitrary-domain fitness, or safe sharing without human
review.
